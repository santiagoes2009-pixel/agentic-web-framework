# Autonomous Agent Web Development Framework (AGENTS)

A clean, modular, and production-ready standard for AI-assisted engineering and autonomous development agents building modern web applications.

## What is this?
This repository provides:
- **`AGENTS.md`**: The universal rulebook and methodology for autonomous coding assistants (Cursor, Windsurf, Copilot, Antigravity, etc.).
- **Architecture Standard**: Clear separation of concerns, high-performance UI patterns, and zero-emoji design rules.
- **Security & Privacy Checklist**: 20 strict security guidelines, HttpOnly session handling, anti-IDOR principles, and legal consent traceability.
- **Edge Deployment**: Standardized Local-First to Cloud deployment commands for Cloudflare Pages and Supabase.

## Repository Contents
- `AGENTS.md`: The complete agent instructions and standards.
- `README.md`: Project documentation and quick start guide.
- `LICENSE`: Open-source MIT License.

## Quick Start
To use this standard in any project, simply copy `AGENTS.md` into the root of your workspace or reference it in your AI coding assistant prompt instructions.
